# POWERSTYLE Stok Yönetimi

`index.html` dosyasına çift tıklayın. Uygulama doğrudan tarayıcıda açılır; sunucu, Terminal veya ek kurulum gerektirmez. Excel dosyasındaki 225 ürünün stok, maliyet ve satış fiyatları uygulamanın içine yerleşiktir.

Uygulama verisi bu klasördeki `stok_verisi.json` dosyasında saklanır. Bu dosya oluşturulduktan sonra her yeni hareket, ürün güncellemesi ve ekleme kalıcıdır. Excel dosyasındaki ilk stok ve maliyet bilgileri içe aktarılır; hareket kaydı bulunmadığı için başlangıç stokları aynen korunur.

Güncellemeler aynı tarayıcıda güvenle saklanır. Uygulamayı başka bilgisayara taşımak için bu klasörün tamamını taşımanız yeterlidir; `index.html` dosyasını açın.
